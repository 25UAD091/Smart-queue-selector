Three-Stage Combinational Path

1. Check availability (A=1).

2. Find the minimum queue length.

3. If tied, select the smaller priority number.

Priority Rule: P1 > P2 > P3.

The output depends only on current inputs; no memory is required.

Project Report Summary

Objective: Select the most suitable service counter using combinational logic.

Inputs: Availability (A), Queue length (Q), Priority (P).

Selection Rule: Select an available counter with minimum queue. If tied, select the smaller priority number.

Applications: Banks, hospitals, railway counters and service centres.
